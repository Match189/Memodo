## 2. 发现并修复的 bug

**N1（Android，崩溃级）**：`Screens.kt MemoListView` 分享文本按 `split('\n', limit=2)` 后直接解构 `(first, rest)`——单行分享文本（绝大多数真实分享都是单行）返回长度 1 的列表，取索引 1 越界 → **FATAL Exception，应用闪退**（17:00:02 真机复现，`Collections$SingletonList.get`）。
**修复**：`parts[0]` + `parts.getOrElse(1) { "" }`；重建并回归验证——单行分享文本正确填入备忘标题草稿框，无崩溃。**修复版 APK（13117918…）已装回手机（18:38）。**

**N2（低，观察项）**：Windows 主窗口/桌面组件的 WPF UIA 树暴露 checkbox `AXToggle`，但派发后 UI 不响应（自绘控件未挂钩 UIA 切换）；`AXPress` 对导航 radio 同样无效。自动化测试要靠原生坐标点击。对真实用户无影响，列为后续 UIA 可访问性改进项。

**N3（低，环境相关）**：MIUI 下应用在后台时用 `am start` 重发 SEND intent 只把已有任务带到前台、不重派发 onNewIntent（系统行为，非应用 bug）；真实用户从系统分享面板进入走标准路径不受影响。
