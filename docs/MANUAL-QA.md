# Memodo 手动回归清单（UI/真机项）

自动测试（服务端 API、加密引擎、WebDAV 协议）已由 `.qa/` 资产覆盖；以下是需要人或真机验证的项目。
建议每次发版前过一遍，约 30 分钟。

## A. Windows 桌面（10 分钟）

1. **升级安装**：用新 publish/ exe 覆盖运行一次，确认设置（主题/语言/同步配置）保留。
2. **同步·WebDAV**：配置坚果云 → 立即同步 → 两台改动互达；删除一项 → 另端消失（墓碑传播）。
3. **同步·服务器**：登录 localhost:8000（或部署地址）→ 立即同步 → 显示"推送/拉取"计数。
4. **E2EE 开启**：设置口令 → 同步成功；到 WebDAV 网盘或服务器数据库确认内容为密文（`TUVNT0RP` 开头 / data 字段非明文）。
5. **E2EE 口令错误**：本机口令与云端不符 → 同步失败且提示口令不一致，本地数据不变。
6. **E2EE 未设口令 + 云端已有密文**（新护栏 W1）：清空本机口令 → 同步 → 应提示"云端已加密但本机未设口令"而非覆盖。
7. **自动同步**：间隔设 1 分钟 → 等待 2 分钟 → 数据自动变化（两通道各试一次）。
8. **口令修改后全量重拉**（新 W3）：改口令 → 同步 → 旧数据仍完整（游标已归零重拉）。
9. 托盘：立即同步 / 显示组件 / 退出；主窗口关闭到托盘。
10. 中英文切换后同步设置卡与关于页无中文残留。

## B. Android 真机（10 分钟）

1. **安装升级**：新 release APK 覆盖安装（签名一致，无需卸载）。
2. **密码迁移**（新 A5）：旧版本已配置 WebDAV 的设备升级后直接同步一次 → 成功（旧明文密码自动迁移 Keystore）。
3. **同步·WebDAV / 服务器**：与 Windows 双向互同步各一次（任务 + 备忘）。
4. **E2EE**：设置相同口令 → 与 Windows 互同步成功；口令设错 → 失败提示、本地不变。
5. **自动同步**（服务器通道，新 A2）：改服务器数据 → 等 2 个周期 → 手机自动拉到；飞行模式 → 状态图标变失败。
6. 小组件：添加、勾选待办、点行跳转；分享文本到"念念"→ 备忘草稿预填。
7. 备份导出 → 清空数据 → 导入还原。

## C. 双端联测（5 分钟）

1. Windows 新增任务 → Android 小组件 2 分钟内出现（自动同步链路）。
2. Android 勾选完成 → Windows 列表划线（反向链路）。
3. 双端同时改同一条（两端各改不同字段）→ 双端各同步一次 → 内容收敛一致（LWW）。
4. 一端删除 → 另端同步后消失 → 一端恢复 → 再同步后回来。

## 已知边界（非 bug，勿报）

- 服务器通道两端口令不一致时：各端只能解密自己加密的行，数据互通不全（设计边界，靠"口令一致"约定 + W1/A1 WebDAV 护栏兜底）。
- WebDAV 云端密文 + 本机从未设过口令 → 同步中止提示（本次新增的正确行为，不是"同步坏了"）。
- 90 天前的墓碑在服务器全量拉取时被清理（设计行为）。
